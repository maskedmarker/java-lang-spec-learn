# java中的运算符

## 取模运算符

数学上通常定义的“模运算”（mod）要求结果 总是非负的。
但在 Java 中，% 实际上是 余数运算（remainder），它的结果符号与被除数（左操作数）相同。
即 Java 的 % 运算结果可以是负数。

```text
例如：

表达式	     数学意义	    Java实际结果	     说明
5 % 3	      2	            2	              正常
-5 % 3	      1 (数学模)	    -2 (Java余数)	  符号与被除数相同
5 % -3	      2 (数学模)	    2	              符号与被除数相同
-5 % -3	      1 (数学模)	    -2	              符号与被除数相同
```

```text
如何获得“数学意义的模”

public static int mod(int a, int b) {
    int r = a % b;
    return (r < 0) ? (r + Math.abs(b)) : r;
}
```
