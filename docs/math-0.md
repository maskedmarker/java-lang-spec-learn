# 计算机中相关的数学

## 二进制补码

```text
简单来说,补码是一种用二进制表示有符号数（正数和负数）的方法.
在一个固定的位数（比如8位）下：
    最高位（最左边的位）是符号位：
    0 表示正数.
    1 表示负数.
    剩下的位表示数值.
    
正数的补码
    规则非常简单：正数的补码就是它本身的二进制表示.    
    
负数的补码
    计算负数的补码稍微复杂一些,但遵循一个清晰的流程.以一个固定的位数（比如8位）为例.
    步骤：
        1.先求对应正数的二进制原码.
            例如,求 -5 的补码,先找到 +5 的二进制.
        2.按位取反（得到反码）.
            将所有位 0 变成 1,1 变成 0.
        3.将反码加 1（得到补码）.    


为什么补码有用？
补码的精妙之处在于,一个数加上它的相反数的补码,结果应该为0（在固定的位数下,溢出的最高位会被舍弃）.
让我们验证 5 + (-5) 是否等于 0： 
   0000 0101  （这是 +5 的补码）
+  1111 1011  （这是 -5 的补码）
---------------
  10000 0000
这是一个9位的结果,但我们的寄存器是8位的,所以最左边的 1 会溢出并被丢弃,最后剩下 0000 0000,也就是十进制的 0.完美！

计算二进制补码是一个非常重要的计算机基础概念.它让计算机能够用同一套电路来进行加法和减法运算. 
```
